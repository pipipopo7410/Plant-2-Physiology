# 植物｜運輸與光合（正式版）

這是「剛剛數位小教室」入口網站中：**植物 → 運輸與光合** 的獨立網站。

## 內容

- A 植物體內運輸：雙子葉、單子葉植物的 3D 水與糖運輸、維管束排列、氣孔、葉內微觀 3D。
- B 光合與呼吸：原版平面操作、日夜切換、分子拖曳、呼吸作用解鎖與比較。
- C 氣孔與蒸散：先比較日夜，再比較乾濕土壤，最後比較濕度、強風與高溫的相對蒸散速率。

## GitHub Pages 上架（不需要執行 npm 或架設伺服器）

1. 建立新的 GitHub 儲存庫，建議名稱：`Plant-Transport-Photosynthesis`。
2. 將這份 ZIP 解壓縮，把**資料夾內全部檔案與 `icons` 資料夾**上傳到儲存庫根目錄，確保 `index.html` 就在根目錄，不是放在另一層資料夾內。
3. 進入 **Settings → Pages → Build and deployment**，選擇 **Deploy from a branch**，Branch 使用 `main`、資料夾使用 `/(root)`，儲存。
4. 發布後，把正式網址填入入口網站「植物 → 運輸與光合」的按鈕。

若 GitHub 帳號是 `pipipopo7410`，且使用上述儲存庫名稱，部署成功後**預期**的網址格式為：

`https://pipipopo7410.github.io/Plant-Transport-Photosynthesis/`

這只是依命名推算的網址，必須先上傳並成功部署才會存在。

## 離線與安裝

本站的 HTML 包含原本教學互動所需程式及內嵌圖片；另附 PWA manifest、圖示與 service worker。
首次在 HTTPS（如 GitHub Pages）連線開啟、等待離線資源快取成功後，可以安裝到主畫面並在後續離線使用。
直接用 `file://` 開啟 `index.html` 仍可測試主程式，但瀏覽器不會為 `file://` 註冊 service worker。
更新網站後，請在線上重新開啟以取得最新版本。
